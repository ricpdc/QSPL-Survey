# QSPL-Survey – Data Analysis

This repository contains the Jupyter Notebook used for the data analysis of an expert survey conducted in the context of a study on variability management in hybrid quantum–classical software systems using Software Product Line (SPL) principles.

The purpose of this repository is to provide transparency and reproducibility of the analyses reported in the associated research paper.

---

## Contents

- **`data_analysis.ipynb`**  
  Jupyter Notebook implementing the complete data analysis pipeline, including:
  - data loading and preprocessing,
  - descriptive statistics,
  - statistical tests,
  - qualitative analysis support,
  - and generation of figures and tables reported in the paper.

The notebook is documented and structured to allow straightforward replication of the reported results.

---

## Replication Package

The **complete replication package**, including:
- the feature model (UVL specification and graphical representations),
- survey instruments and datasets,
- qualitative coding artifacts,
- and additional documentation,

is publicly available on Zenodo at the following DOI:

**https://doi.org/10.5281/zenodo.18248594**

Researchers interested in fully replicating or extending the study should consult the Zenodo replication package in conjunction with this repository.

---

## Reproducibility

To reproduce the analysis:

1. Clone this repository.
2. Download the datasets from the Zenodo replication package.
3. Place the data files in the directory structure expected by the notebook.
4. Open `data_analysis.ipynb` in a Jupyter environment and execute the cells in order.

---

## Intended Use

This repository is intended for:

- Reproducing the survey data analysis.
- Inspecting the statistical and methodological procedures used in the study.
- Supporting secondary analysis or methodological extension
